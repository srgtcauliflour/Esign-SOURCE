About SideVault

SideVault is a self-hosted app for browsing community IPA sources, downloading your own App Store apps, and resigning any .ipa with your own certificate for over-the-air install.

  • Downloads only apps tied to the Apple ID that requests them — you must own or have a free license for the app.
  • Runs best on your own machine or private network. If you expose it to other people over a real network, put it behind HTTPS and set COOKIE_SECURE=true and TRUST_PROXY=true.
  • Each browser session gets its own sandboxed storage for ipatool credentials, uploaded certificates, and downloaded/signed .ipa files; nothing is shared across sessions, and it's wiped on sign-out or after 24h idle.
  • Over-the-air install (itms-services://) only works from an HTTPS host opened in Safari on the device — plain HTTP or other browsers won't trigger the install prompt.
